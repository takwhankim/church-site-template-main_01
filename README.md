# 온맘교회 홈페이지 콘텐츠 관리

이 저장소는 온맘교회 홈페이지와 TinaCMS 편집 화면을 한 프로젝트로 관리합니다. 기존 페이퍼교회 프로젝트와는 별도입니다.

## 편집할 수 있는 항목

- 첫 화면 문구와 히어로 이미지
- 홈페이지 로고 (헤더·푸터 공통)
- 설교 제목, 날짜, 본문, 요약, YouTube 링크
- 교회 소식 게시글, 대표 사진과 추가 사진 갤러리
- 주보 PDF 주소
- 새가족 안내, 주소·연락처·지도 링크
- 홈페이지 안내 메뉴 문구

## 환경 변수

TinaCloud 프로젝트 연결 후 호스팅/빌드 환경에 다음 변수를 비밀값으로 등록합니다.

- `NEXT_PUBLIC_TINA_CLIENT_ID`: 온맘교회 TinaCloud 프로젝트 ID
- `TINA_TOKEN`: 해당 프로젝트의 읽기 토큰. 저장소 파일에 직접 넣지 않습니다.
- `GITHUB_BRANCH`: 기본값은 `main`

## 명령

- `npm run cms`: 로컬 미리보기와 편집기를 실행합니다.
- `npm run build`: `tina/config.ts`를 기준으로 `/admin` 편집 화면을 생성합니다.

편집한 콘텐츠는 `content/site.json`에 저장되고, 업로드한 이미지는 저장소의 `uploads/` 경로에 저장됩니다. 호스팅을 연결한 뒤 홈페이지의 `/admin/` 경로에서 관리하게 됩니다.
